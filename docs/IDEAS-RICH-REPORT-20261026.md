### 已发现并修复

1. Windows静态服务把`.js`返回text/plain导致OCR Worker `importScripts`失败（原栈位于blob Worker第1行）。暂停后核实HTTP头，使用同字节正确MIME的.mjs，实际中文识别重测通过。
2. 中途一次补丁引入`ideas-editor.js:11`语法错误并引起`ideas-ui.js:119`初始化连锁TypeError；立即停下修复原语法，未用空catch屏蔽，最终语法和控制台重测为空。
3. 刷新详情返回列表偶发约55px偏移；图片尺寸未就绪先恢复scrollTop。现在预留真实宽高比例、原History位置在图片布局准备好后补恢复；用户已开始操作则不再改位置。补测记录前/后位置一致（例如1306px，见测试日志）。
4. 图片超限提示被稍后的草稿成功提示覆盖；保留错误直到下一次实际编辑，不显示假的添加成功。

失败试跑保留在work，最终通过以表中结果为准，旧结果不删除、不当作当前通过。
