## 限制与验收

- 尚未测试实体iPhone/Safari的惯性滚动、系统键盘、真实安全区或PWA独立窗口；本项目仍无PWA实现，不据Chrome触摸模拟声称实机通过。
- 社交仍为合成/当前会话演示，无云社区、真实来源标签或持久社交备份。刷新临时帖子消失仍显示原明确提示。
- 查看日期不作为新增永久设置写入JSON；新浏览器会话使用原默认/备份日期，不承诺云同步或跨设备日期恢复。
- 真实用户v9下载/恢复、万级连续账单性能尚未验证。完整用户数据备份仍需由用户在日常原来源导出v9。
- 本机打开地址仍为`http://127.0.0.1:8000/`，服务需运行；不更换来源以免看似数据消失。手机模拟器可先验收社交滚动、搜索返回、收支统计返回、两个模块分别选日及说明入口。
