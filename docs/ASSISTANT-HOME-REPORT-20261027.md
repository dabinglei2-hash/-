## 页面与数据行为

- 五导航仍为首页/助手/收支/社交/我的；助手仍使用旧URL **#records** 和records-section，不破坏收藏及历史访问。页面只有“助手”与未启用说明，没有聊天框、模拟回复、AI按钮或原六个入口。
- 从助手移除妙想、习惯、长期目标、学习、日程、完整今日回顾的入口；这些模块/原URL/表单/记录均保留。妙想/学习/日程仍从原首页卡进入，完整回顾仍可直接访问#today-record或经日报关联记录进入；首页快速记录不改。
- 原六张首页卡保持内容与几何；在笔记卡后追加同排两卡：左 **习惯（#habits）**，右 **长期目标（#goals）**。使用原home-card和habit/goal SVG，整卡单一链接，无嵌套打卡按钮。
- 习惯摘要按首页所选日期读取原checkedDates，历史用“当日”，点击将原personal-date视图定位同日。目标摘要统计所有原goals的completed状态，不受首页日期筛选，不编造连续天数或阶段进度。资料读取错误显示“—/暂不可读取”，不写零覆盖。
- 原打卡、新增、完成状态、确认删除、详情及目标时间线保留。当前目标模块未提供单独标题/备注编辑器或多阶段引擎，本轮没有伪称新增这些能力。
- 习惯/目标及详情选中首页；正常返回仍按来源History恢复日期/位置，直接#habits/#goals后备首页，详情后备各自原列表；其他模块规则不改。
- 习惯/目标仍为原personal存储的habits/goals；日报关联、记录ID、历史正文、币种/统计算法、十个存储键及完整v11/兼容v5–v10链路不改。
