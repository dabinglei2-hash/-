## 推荐实现

1. 新增独立可选 `my-life-dashboard-notes-v1`：本地纯文本笔记、Notion 页面身份/基线及待同步编辑、必要缓存与同步时间；读取空值不自动初始化。原九键和旧记录不迁移。
2. 本地创建/原 ID 编辑/确认删除、搜索、分类、更新时间排序、详情/来源返回、失败保留输入。同步本地笔记必须明确点击；不自动上传已有本地内容。
3. Token 只由可选本机服务的环境变量读取，前端不能输入/保存 Token。使用 Python 标准库建立同源代理；仅绑定 loopback，校验 Host/Origin/内容类型/请求大小，固定 Notion 官方目标和授权数据源，禁止任意 URL 代理。静态站仍可使用本地功能；没有代理/配置时明确未连接。

5. 中文配置说明使用 Internal Integration 与指定数据源；不建立 OAuth/账号系统、不远程部署、不索取聊天中的 Token。新增依赖为零。
