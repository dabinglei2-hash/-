完成：2026-10-23（2026-10-22开始）。基于当前项目增量修改，保留此前未提交日程工作；用户已批准[方案A](LEARNING-EXTENSION-PROPOSAL.md)。没有部署、安装依赖或操作真实浏览器数据。

## 1. 使用方式和入口

从原来使用的网站地址打开，首页学习卡片或记录页“学习”均到同一个`#learning`，首页卡片位置/大小及五导航保留。内部返回沿用原History来源，学习/日程/记录详情可返回原查看上下文；直接打开则安全返回记录页。

- **首页**：所选日期实际分钟、当天目标/进度、最近三条记录、开始学习/新增记录。日期沿用全站selected-date，可选历史日期或返回今天。
- **计划**：新建或明确关联已有日程，设置预计分钟、日期和原日程优先级；状态与日程同一taskId。点击任务进原详情，保留前后切换。编辑保留原ID和完成状态；取消关联不删日程，删日程仅归档学习关联。计划分钟始终不算实际。
- **专注**：选择计划或自由主题，开始/暂停/继续/结束/取消。刷新或离开保留计时；结束先存待确认状态，再由用户确认实际日期及完整分钟。固定预留ID，重复保存不会产生第二条。零头保留在历史，不足1分钟可继续，超过1440分钟提示手动拆分。计时不自动完成任务。
- **统计**：日/自然周/月实际分钟、当日目标完成率、周/月每日趋势及可展开明细、最近记录，沿用insights原口径。
- 原学习表单、日期/关键词历史、十条分页、原ID编辑、确认删除及详情集中在**首页 → 学习记录与历史**；日报关联明细仍回对应日报编辑。没有增加旧模型不支持的备注/起止字段。
