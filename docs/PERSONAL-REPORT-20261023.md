## 4. 备份安全与使用

我的 → 数据备份 → **导出完整JSON v8**。浏览器发起文件下载后，应在下载列表确认保存并检查JSON；应用不会自动上传或备份，不知道实际文件是否已落盘。

导出区域仅显示本次会话发起操作的实际时间及版本，刷新清除；它不是最近成功备份时间。没有新增用于伪造“最近备份成功”的持久字段。

恢复流程：选以前导出的JSON → 严格校验/预览类别数量和版本 → 可选“先导出当前完整数据”并确认下载完成 → 点击安全合并 → 二次确认。取消不写入，相同数据跳过，冲突停止，不自动覆盖。运行计时在v8副本暂停、恢复后手动继续仍由原机制处理。多键回滚不是数据库原子事务。

所有浏览器验证均为新上下文及合成数据。已实际演练合成v8完整恢复及旧版兼容，**未核实真实用户JSON的新鲜度与恢复能力**，不连接日常浏览器配置。
