## 打开网站

请继续使用原来的浏览器和打开地址，刷新即可加载这轮修改。Windows 可按 `Ctrl + F5` 重新加载页面文件；这不会清空 localStorage。

- 已经通过双击 `index.html` 使用网站：继续从同一个文件地址打开。
- 已经通过本机服务器使用网站：继续使用原来的主机名和端口。
- 浏览器按“来源”隔离数据。文件地址、`localhost:8000` 和 `127.0.0.1:8000` 的数据不共享。需要更换打开方式时，先在原地址导出 JSON，再在新地址检查摘要并确认导入。

若首次使用本机服务器，并且电脑已有 Python：在项目文件夹地址栏输入 `powershell`，进入命令行后执行：

```powershell
python -m http.server 8000 --bind 127.0.0.1
```

该命令只在电脑本机提供网页，随后在浏览器打开 `http://127.0.0.1:8000`。用完按 `Ctrl + C` 停止。无需安装前端框架，也不会发布网站。

## 五个主要入口

- **首页**：居中昵称头像、日历和搜索入口；学习、妙想、收支、任务四卡统一显示所选日期。卡片进入对应日期；右下角圆形按钮打开快速记录 Sheet，可分别新增学习、收入/支出或任务。任务新增和清单在工作计划页。
- **记录**：妙想、习惯、长期目标三个主要入口；学习详情、工作计划和完整今日回顾在下方。
- **收支**：本月汇总、分类概览、分页账单列表；“新增”以底部 Sheet 打开原账单表单，编辑和删除入口收在每笔账单的“更多操作”里。
- **统计**：按周、月、年查看趋势、学习与任务汇总，以及收入/支出分类排行。
- **我的**：个人资料、成长与财富数据、技能进度，以及独立“设置”入口。

手机使用固定底部导航，电脑使用左侧导航。二级页面有返回按钮；正常从列表打开详情时，返回会尽量恢复分页、筛选和列表滚动位置。直接打开详情链接时，返回对应列表。

## 记录今天

1. 点击首页右下角黑色圆形铅笔按钮，选择学习、收入/支出或任务。
2. 只填写所选类型需要的信息；日期自动沿用首页当前选择日期，收支分类沿用现有分类。
3. 保存成功后 Sheet 自动关闭，回到原页面并显示简短提示；保存失败时面板和输入内容保留。
4. 需要填写完成事项、精力或总结时，到“记录 → 完整今日回顾”。重复保存会更新当天已有日报及关联的学习/收支流水，不再次累加。
5. 快速记账金额不可留空；明确填写 0 USD 与未填写状态不同。

页面内二级入口在顶部提供统一返回按钮。按钮返回会遵循当前浏览器历史；浏览器后退、前进也会同步页面。快速记录 Sheet 自身占用一条同地址历史状态，因此按浏览器后退会先关闭 Sheet。

页面切换使用轻量淡入和微移，不依赖浏览器 View Transition API，以避免设备旋转或窗口尺寸变化中断转场。新增账单 Sheet 支持背景关闭、取消、Esc、浏览器返回和键盘焦点循环；编辑/删除操作采用紧凑菜单，删除继续要求确认。保存异常通过应用内提示反馈，并尽可能恢复为已持久化的数据快照。系统启用“减少动态效果”时会停用非必要动画。

如果两个标签页同时编辑同一天，较旧表单会停止保存并保留当前输入，避免覆盖另一页的新内容。遇到提示时，先复制需要保留的草稿，再刷新并编辑最新记录；其他日期或独立账单的新增不会阻止本次保存。

原有学习详情、收支明细、独立记录编辑与工作计划继续保留。编辑独立记录保留原 ID 和创建时间；关联日报的流水通过对应日期的日报统一编辑。

## 妙想、习惯和目标

原“每日笔记/日记”在界面中统一称为“妙想”，底层仍使用原 diary 数组、ID、日期、标题、正文及创建时间。不会把历史正文中的井号自动转换为标签。

- 历史列表每页10条，支持内容关键词、标签、日期的交集筛选；“清除筛选”回到全部。详情返回恢复筛选、页码与列表位置。
- “新建妙想”展开原表单。点击“# 标签”，输入名称后回车或点“添加”；也可点击已有标签复用。点击已选标签可移除。
- 首尾空白和开头井号会整理，大小写等价标签去重；每条最多20个标签，每个1–30字。特殊字符按文字显示。
- 编辑会更新同一记录，保留ID和创建时间；另一页已更新正文或标签时停止旧编辑保存。删除前确认，取消保留。
- 未保存的妙想和日报在站内切换后保留；关闭或刷新页面时，浏览器可能提示未保存内容。草稿不上传，也不会作为演示数据写入存储。
- 习惯页面默认显示今天，勾选立即保存，历史进入详情。
- 长期目标保留原完成状态、截止日期和备注，时间线默认折叠，没有编造额外阶段数据。

## 全站搜索

首页右上角放大镜进入搜索。检索已保存的妙想、任务、学习、收支、习惯、长期目标和个人资料；默认全部日期，不受首页日期暗中限制。

可以选择内容类型和日期。目标以截止日期匹配；习惯以实际打卡日期匹配；无日期的个人资料仅在“全部日期”下出现。空关键词不显示结果，缺失记录会提示重新搜索。结果进入实际详情，返回恢复关键词、类型、日期、页码和列表位置。搜索只在本机记录中运行。

## 快速记账与分类

1. 进入“收支 → 新增”。
2. 选择收入或支出、分类，输入 USD 金额；日期默认今天，备注可选。
3. 保存后返回收支，列表显示正负号及文字区分方向。
4. 空白金额会被阻止；明确输入 0 可以保存一笔有方向和分类的零金额账单。
5. 需要同时填写收入和支出时，打开“筛选账单 → 完整记账表单”。旧混合账单继续保留两项金额，编辑不会拆分旧记录。

“管理分类”支持新建、改名、停用和恢复，不提供真正删除分类的操作。

- 分类使用稳定 ID，账单关联另行保存，并保留记账时的分类名称快照。
- 改名只影响后续选择和排行的当前名称；旧账单显示保存时的名称。
- 停用后不再用于新增账单，历史账单和排行仍保留；恢复后可再次选择。
- 旧账单没有分类信息时显示“未分类”，不会根据备注猜测或改写旧数据。
- 排行按稳定 ID 汇总；同一分类在改名前后的金额归为同一组。

账单可以按所选日、近 7 天、所选月、全部日期或自定义区间筛选，并按备注搜索，每页 10 条。首页收支卡进入时，列表定位所选日期，顶部保留所选月份的月汇总。手机长账单列表在自己的区域滚动。

## 周、月、年统计

- 周：参考日期所在的周一至周日，包含跨月和跨年边界。
- 月：自然月；年：自然年。
- “本期”回到当前日期所在的范围。
- 趋势图一次显示收入、支出或结余中的一个，结余始终为收入减支出。
- 分类排行可以切换收入或支出，按金额从高到低排列；未分类金额也参与统计。
- 学习时长、学习天数和任务完成率来自原记录，不重复加入日报数值。
- 空范围显示“暂无记录”，不生成示例账单。
- “月度明细 · 学习与任务”保留原年份/月选择、月汇总与每日明细；月模式下和主统计月份联动。

3. 分类设置可以新建、改名、选择图标、停用与恢复。改名不会改写历史账单保存时的名称。
4. 点击收入/支出金额查看单笔排行，支持按金额或时间排序。账单入口查看年度各月汇总，点击月份回到对应流水。
5. 预算可以设置整月预算或某个支出分类预算；剩余金额按该月份真实支出计算。分类预算不重复叠加进总预算。
6. 资产页记录手动资产/负债余额快照。它与流水和原财富目标分别计算，不自动生成账单，也不连接银行。账户可编辑、归档和恢复。
7. 在统计页点分类排行，查看该分类的真实趋势和流水。周/月/年、日期、排序、分页保存在详情链接中，返回恢复来源页面。
